# A Little Birthday Surprise

Open `index.html` in a browser to enjoy the complete birthday experience. Everything works locally; the optional typeface is loaded from Google Fonts, with system font fallbacks if you are offline.

## Make it personal

Open `script.js` and edit the clearly marked `CONFIG` near the top:

- `friendName` changes the greeting on the birthday letter.
- `birthdayMessage` is an array of paragraphs; edit or add lines to make the typewriter note yours.
- `photos` controls the four gallery image paths and captions. Replace the image files and update each `src` to add or change memories.
- `memories` contains the five editable friendship-story dates, titles, and descriptions.
- `reasons` contains the animated reasons cards and their icons.

Keep replacement photos in the project and use their relative paths, so the gallery and full-screen photo view both work offline. The gallery currently shows the birthday photo in `1.jpeg` and three trip photos in `images/memory-02.jpeg` through `images/memory-04.jpeg`.

## Music

The music button starts audio only after it is clicked. By default, it plays a gentle melody generated by the browser. To use your own song instead, place an audio file in the project (for example `audio/our-song.mp3`) and set `musicSrc` in `script.js` to `"audio/our-song.mp3"`. The file stays on your device; use music you have permission to share.

## Customize the hidden letter

Edit the letter text inside the `letter-dialog` element in `index.html`. The opening welcome, final message, and other section headings are also plain HTML text and can be changed there.
